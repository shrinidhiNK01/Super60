Why System Design :-
1)Slow Process of application when multiple users   --------------  LLD and DSA
2)Cannot hold load of multiple users 
3)Users are Increasing   -------------------------  Vertical Scaling(Instead of addiing new server , update the current server effeciently)
4)users high waiting time -------------------------- Horizontal Scaling(Add multiple servers, add multiple database)
5)Need of Centralized data
6)Utilize Underutilized counters   ------------------- Load Balancer(Distribute the load to multiple servers)

all of the apps use system design
